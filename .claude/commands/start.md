# START COMMAND

Start a new engineering task.

Do not modify source code.

Ask the developer to provide the requirement using:

## FEATURE / BUG

What needs to be built or fixed?

## BUSINESS OBJECTIVE

Why is this required?

## EXPECTED BEHAVIOR

What should happen?

## ACCEPTANCE CRITERIA

How will we know it is complete?

## CONSTRAINTS

Any technical or business constraints?

## REFERENCE

Provide any relevant:

* Confluence page
* ticket
* API documentation
* screenshots
* design
* existing implementation

If the developer provides enough information, proceed to requirement analysis.

If important information is missing, ask focused questions.

Do not implement anything during this command.
