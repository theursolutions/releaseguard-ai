# STATUS COMMAND

Determine the current state of the active engineering task.

Do not modify code.

Identify:

## REQUIREMENT

What feature/bug is currently being worked on?

## CURRENT PHASE

One of:

* REQUIREMENT
* CLARIFICATION
* PLANNING
* WAITING FOR APPROVAL
* IMPLEMENTATION
* TESTING
* REVIEW
* AUDIT
* COMPLETE
* BLOCKED

## APPROVAL

Is implementation approved?

## IMPLEMENTATION

What has been completed?

## TESTING

What has been tested?

## REVIEW

What reviews have been completed?

## AUDIT

What requirements have passed?

## BLOCKERS

What is currently preventing completion?

## NEXT ACTION

State exactly one next action.

Do not perform the next action automatically.
